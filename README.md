# 타이머신 · Timerchine

**알람이 울리는 순간도, 음악이 멈추는 순간도 시간의 신호로.**

타이머신은 시간이 끝나면 소리가 울리는 기본 알람을 제공하는 Windows용 멀티 타이머입니다.

정해진 시간 동안 무언가를 하거나, 때가 될 때까지 기다려야 한다면 **역알람 모드**를 선택하세요. 타이머가 작동하는 동안 좋아하는 음악을 들으며 다른 일을 하고, 음악이 끊기는 순간 시간이 됐음을 떠올릴 수 있습니다.

역알람은 음악이 멈추는 변화를 알아차릴 수 있는 상황에 어울립니다. 수면 중처럼 그 변화를 놓치기 쉬운 상황에서는 소리가 울리는 기본 알람을 사용하세요.

## 주요 기능

- 여러 타이머와 개별·전체 시작, 중단, 재시작
- 기본 알람과 선택형 역알람, 타이머별 음량 및 단축키
- 로컬 파일, 재생 목록과 무작위 재생
- 기본 프리셋 자동 생성과 이름을 지정하는 재생 목록 프리셋
- 새 프리셋 생성 즉시 선택, 재생 목록 저장 시 선택한 프리셋 갱신
- 모래시계 표시와 트레이 최소화
- 대기·중단 상태에서는 시간 입력칸 배경 표시, 실행 중에는 숨김

## 다운로드와 실행

버전별 실행 파일과 자료는 [Releases](https://github.com/lch2301/Timerchine/releases)에서 확인할 수 있습니다.

Windows 10 22H2 이상 또는 Windows 11 x64를 대상으로 합니다. Windows용 ZIP을 압축 해제한 뒤 `Timerchine.exe`를 실행하세요. 자체 포함 배포본은 .NET 런타임을 별도로 설치하지 않고 사용할 수 있습니다.

1.2.0 실행 파일은 관리자 권한을 요청합니다. 미서명 배포본은 Windows 보안 설정에 따라 실행 안내가 표시되거나 실행이 제한될 수 있습니다. 다운로드한 파일의 SHA256은 함께 제공되는 해시 파일과 대조할 수 있습니다.

## 사용 방법

1. 시·분·초 숫자칸을 눌러 시간을 입력합니다. 엔터를 누르거나 다른 영역을 클릭하면 저장됩니다.
2. 알람 설정에서 기본 알람 또는 역알람과 재생할 소리를 선택합니다.
3. 시작을 누릅니다. 중단한 타이머는 재시작할 수 있으며, 역알람은 중단한 재생 위치에서 이어집니다.
4. 재생 목록을 반복 사용할 때는 프리셋을 만들거나 불러온 뒤 재생 목록 창에서 저장합니다.

외부 링크를 사용할 때는 콘텐츠의 권리와 제공 사이트의 이용 조건을 확인하고, 사용할 권한이 있는 자료를 등록하세요. 앱 설정의 이용 권한 확인은 콘텐츠 이용 허락을 대신하지 않습니다.

자세한 조작과 데이터 저장 위치는 [사용 안내](docs/USAGE.ko.md)를 확인하세요.

## 설정과 프리셋

설정·프리셋·미디어 캐시는 `%LOCALAPPDATA%\IntervalTimer`에 보관됩니다. 배포 ZIP에는 사용자의 개인 설정이나 개인 알람 파일이 포함되지 않습니다.

1.2.0은 같은 실행 파일을 다시 실행하면 타이머 설정을 복원합니다. 새 빌드로 바꾸면 타이머 설정이 초기값으로 시작할 수 있으며, 프리셋 라이브러리는 별도 파일로 유지됩니다.
