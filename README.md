# 타이머신 · Timerchine

**알람이 울리는 순간도, 음악이 멈추는 순간도 시간의 신호로.**

타이머신은 시간이 끝나면 소리가 울리는 기본 알람을 제공하는 Windows용 멀티 타이머입니다.

정해진 시간 동안 무언가를 하거나, 때가 될 때까지 기다려야 한다면 **역알람 모드**를 선택하세요. 타이머가 작동하는 동안 좋아하는 음악을 들으며 다른 일을 하고, 음악이 끊기는 순간 시간이 됐음을 떠올릴 수 있습니다.

역알람은 음악이 멈추는 변화를 알아차릴 수 있는 상황에 어울립니다. 수면 중처럼 그 변화를 놓치기 쉬운 상황에서는 소리가 울리는 기본 알람을 사용하세요.

## Android 버전

Android 8.0 이상용 소스는 [mobile/android](mobile/android)에 있습니다. 기본 알람·역알람·재생 목록·프리셋을 제공하며, Windows의 트레이 최소화는 **화면을 꺼도 이어지는 백그라운드 재생과 미디어 알림 제어**로 바뀌었습니다.

Android APK와 해당 소스는 [Android 릴리스](https://github.com/lch2301/Timerchine/releases/tag/android-v1.2.0)에서 제공합니다. 모바일의 파일·링크 지원 범위, 설치와 사용 방법은 [Android 안내](mobile/android/README.md)를 확인하세요.

## 주요 기능 (Windows)

- 여러 타이머와 개별·전체 시작, 중단, 재시작
- 기본 알람과 선택형 역알람, 타이머별 음량 및 단축키
- 로컬 파일, 재생 목록과 무작위 재생
- 기본 프리셋 자동 생성과 이름을 지정하는 재생 목록 프리셋
- 새 프리셋 생성 즉시 선택, 재생 목록 저장 시 선택한 프리셋 갱신
- 모래시계 표시와 트레이 최소화
- 위치·투명도·이름과 시간의 글자 크기·이름 가로 정렬을 조절할 수 있는 반투명 게임 오버레이
- 대기·중단 상태에서는 시간 입력칸 배경 표시, 실행 중에는 숨김

## 다운로드와 실행

버전별 실행 파일과 자료는 [Releases](https://github.com/lch2301/Timerchine/releases)에서 확인할 수 있습니다.

Windows 10 22H2 이상 또는 Windows 11 x64를 대상으로 합니다. Windows용 ZIP을 압축 해제한 뒤 `Timerchine.exe`를 실행하세요. 자체 포함 배포본은 .NET 런타임을 별도로 설치하지 않고 사용할 수 있습니다.

1.3.0 실행 파일은 관리자 권한을 요청합니다. 미서명 배포본은 Windows 보안 설정에 따라 실행 안내가 표시되거나 실행이 제한될 수 있습니다. 다운로드한 파일의 SHA256은 함께 제공되는 해시 파일과 대조할 수 있습니다.

## 사용 방법

1. 시·분·초 숫자칸을 눌러 시간을 입력합니다. 엔터를 누르거나 다른 영역을 클릭하면 저장됩니다.
2. 알람 설정에서 기본 알람 또는 역알람과 재생할 소리를 선택합니다.
3. 시작을 누릅니다. 중단한 타이머는 재시작할 수 있으며, 역알람은 중단한 재생 위치에서 이어집니다.
4. 재생 목록을 반복 사용할 때는 프리셋을 만들거나 불러온 뒤 재생 목록 창에서 저장합니다.

외부 링크를 사용할 때는 콘텐츠의 권리와 제공 사이트의 이용 조건을 확인하고, 사용할 권한이 있는 자료를 등록하세요. 앱 설정의 이용 권한 확인은 콘텐츠 이용 허락을 대신하지 않습니다.

자세한 조작과 데이터 저장 위치는 [사용 안내](docs/USAGE.ko.md)를 확인하세요.

## 게임 오버레이 (Windows 1.3.0)

게임 창이 활성화되면 타이머 이름과 남은 시간을 표시합니다. 기본 위치는 오른쪽 끝, 위에서 30% 지점이며, 기본적으로 이름과 시간의 오른쪽 끝이 맞춰집니다. 시간은 항상 우측 정렬합니다. 반투명한 글자만 표시하며 마우스 입력과 키보드 포커스는 게임으로 유지됩니다. 브라우저나 바탕화면 등 다른 창으로 전환하면 숨겨지고, 타이머신을 트레이로 최소화해도 사용할 수 있습니다.

앱의 **설정 → 오버레이 → 오버레이 설정**을 열면 위치·투명도·시간 글자 크기·이름 글자 크기를 조절할 수 있습니다. **이름 가로 정렬** 게이지는 0~100% 사이에서 연속으로 조절하며, 0%는 시간의 왼쪽 끝, 50%는 실제 시간 글자와 이름의 가로 중심, 100%는 시간의 오른쪽 끝에 맞춥니다. 팝업 안의 실시간 미리보기로 확인한 뒤 저장하세요. 취소하면 기존 설정을 유지하며, 저장한 오버레이 설정은 앱을 종료하거나 업데이트해도 유지됩니다. 자세한 범위와 조작은 [사용 안내](docs/USAGE.ko.md#게임-오버레이)를 확인하세요.

새 설정의 기본값은 가로 100%·세로 30%·투명도 50%·남은 시간 15.0pt·타이머 이름 13.0pt·이름 가로 정렬 100%입니다. 이전에 저장한 이름의 좌측·중앙·우측 정렬은 각각 0%·50%·100%로 이어집니다. 다른 오버레이 설정도 유지하며, 새 항목이나 저장값이 없는 항목에만 기본값을 적용합니다.

설정의 **게임 오버레이 표시**로 켜거나 끌 수 있으며 처음에는 켜져 있습니다. 창모드와 테두리 없는 전체화면을 지원합니다. 독점 전체화면은 지원하지 않습니다. 그래픽 API 모듈과 게임 엔진·설치 경로, 3D GPU 활동을 조합해 자동 감지합니다. 모듈 조회가 제한된 게임은 게임 엔진 창 정보나 운영체제의 3D GPU 활동으로 감지합니다. 자동 분류가 모든 프로그램의 게임 여부를 보장하지는 않습니다.

## 설정과 프리셋

설정·프리셋·미디어 캐시는 `%LOCALAPPDATA%\IntervalTimer`에 보관됩니다. 배포 ZIP에는 사용자의 개인 설정이나 개인 알람 파일이 포함되지 않습니다.

앱 버전이나 컴파일 빌드가 달라져도 타이머·앱 설정·단축키·재생 목록·선택한 프리셋과 프리셋 라이브러리는 유지됩니다. 새로운 설정 항목에만 기본값을 적용하며, 업데이트를 이유로 기존 저장값을 초기화하지 않습니다. Android도 같은 보존 원칙을 적용합니다.
