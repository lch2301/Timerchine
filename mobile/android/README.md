# 타이머신 Android 1.2.0

원하는 시간이 되면 소리로 알려주는 타이머입니다. 기본 알람을 사용하거나, 음악이 멈추는 순간을 알림으로 삼는 **역알람 모드**를 선택할 수 있습니다.

역알람은 정해진 시간 동안 무언가를 하거나 때가 될 때까지 기다릴 때, 음악을 들으면서 다른 일을 하다가 음악이 끊기는 순간을 알아차리는 방식입니다. 수면 중이거나 소리가 멈춘 것을 알아차리기 어려운 상황에서는 기본 알람을 사용하세요.

## 다운로드와 설치

[GitHub Releases](https://github.com/lch2301/Timerchine/releases)에서 Android 릴리스의 `Timerchine-1.2.0-android.apk`를 받아 설치하세요. **Android 8.0 이상**을 지원합니다. Windows용 ZIP은 Android에서 실행되지 않습니다.

APK를 연 앱에 대해 Android의 ‘이 출처 허용’ 설정이 필요할 수 있습니다. 타이머를 시작할 때 시스템이 요청하는 알림 권한과 ‘알람 및 리마인더’를 허용해 주세요. Android 버전에 따라 정확한 알람 권한은 설치할 때 자동으로 부여될 수 있습니다.

## 주요 기능

- 여러 타이머와 개별·전체 시작, 중단, 재시작
- 기본 알람과 선택형 역알람, 타이머별 음량
- 휴대전화의 음원 파일, 공개 영상·음원 링크, 재생 목록과 셔플
- 링크 제목·썸네일 미리 보기, 다운로드 진행률과 기기 내 음원 캐시
- 이름을 정해 저장하고 불러오는 재생 목록 프리셋
- 남은 시간을 보여주는 모래시계와 중단 상태의 시간 입력 영역
- 화면을 나가거나 잠근 상태의 역알람 음악 재생, 알림의 제어 버튼
- 시작·중단 효과음과 내장 알람음, 재생 시간 표시

Windows의 트레이 최소화는 Android의 **백그라운드 재생과 재생 알림**으로 바뀌었습니다. 외부 링크는 PC와 같은 yt-dlp 추출 엔진을 사용하며, Android용 Python·QuickJS·FFmpeg를 포함합니다.

## 재생 목록과 프리셋

처음에는 ‘기본 프리셋’이 하나 생성되어 선택됩니다. 재생 목록의 **프리셋** 버튼에서 다른 프리셋을 만들거나 불러올 수 있습니다. 새 프리셋을 만들면 바로 선택되며 프리셋 팝업이 닫힙니다.

선택된 프리셋의 내용은 재생 목록에서 **저장**을 눌렀을 때 갱신됩니다. 새 프리셋을 만들면 편집 중인 목록을 유지하며, 기존 프리셋의 **불러오기**를 누르면 그 프리셋의 목록과 셔플 설정을 가져옵니다.

재생 목록을 타이머에 적용하려면 재생 목록 창을 저장한 다음 **알람 설정에서도 저장**하세요.

음원은 기기의 파일 선택기나 HTTP·HTTPS 링크로 추가할 수 있습니다. 확장자가 없는 공개 콘텐츠 페이지도 yt-dlp가 지원하면 제목과 썸네일을 확인하고 음원을 준비할 수 있습니다. 저장 시 내려받은 음원은 기기에 보관하여 이후 재생에 사용합니다. 로그인·연령·지역 제한 콘텐츠, 실시간 방송, DRM과 암호화·분할 스트림은 PC 1.2.0과 같은 기준으로 제외합니다. 주소를 추가할 때는 다운로드·개인 알람 이용 권한을 확인하고 원래 서비스의 이용 조건을 따라 주세요.

## 사용과 데이터

자세한 사용법과 백그라운드 동작은 [사용 안내](docs/USAGE.ko.md), 저장하는 정보와 연결 방식은 [개인정보 안내](docs/PRIVACY.ko.md)에 정리했습니다. PC 버전처럼 새 컴파일 빌드로 업데이트하면 **타이머와 일반 설정은 기본값으로 초기화하고, 저장한 프리셋은 유지**합니다. 필요한 프리셋을 다시 불러와 타이머에 적용하고, 외부 링크 이용 확인과 화면 닫기 방식 등도 다시 설정해 주세요. 내려받은 음원 캐시는 업데이트만으로 삭제하지 않습니다. 앱을 삭제하거나 앱 데이터를 지우면 앱에 저장한 내용도 삭제됩니다.
