# 타이머신 Android 1.2.0

타이머신을 Android에서도 사용할 수 있습니다. 기본 알람은 시간이 끝나면 소리로 알려주며, 선택형 **역알람 모드**는 시간이 흐르는 동안 음악을 재생하고 종료 시 음악을 멈춰 알려줍니다.

정해진 시간 동안 무언가를 하거나 때가 될 때까지 기다릴 때, 음악을 들으면서 다른 일을 하다가 음악이 멈추는 순간을 알아차릴 수 있습니다. 수면 중처럼 음악이 끊긴 것을 알아차리기 어려운 상황에서는 기본 알람을 사용하세요.

## Android에서 제공하는 기능

- 여러 타이머와 개별·전체 시작, 중단, 재시작
- 기본 알람·역알람, 타이머별 음량과 모래시계 표시
- 로컬 음원과 공개 영상·오디오 링크, 재생 목록·셔플·이름 있는 프리셋
- 링크 제목·썸네일·다운로드 진행률, 기기 내 음원 캐시와 파일 위치 안내
- 내장 알람음·시작 및 중단 효과음·재생 시간
- 기본 프리셋 자동 생성과 선택, 재생 목록 저장 시 선택한 프리셋 갱신
- 중단 상태의 시간 입력 배경과 사각형 중단 아이콘
- 앱을 나가거나 화면을 잠근 상태의 음악 재생과 알림 제어

Windows의 트레이 최소화 기능은 Android의 백그라운드 재생과 미디어 알림으로 바뀌었습니다. 공개 콘텐츠의 외부 링크 준비에는 PC와 같은 yt-dlp 엔진을 사용하며, 범용 코덱 처리는 Android용 FFmpeg를 사용합니다.

## 설치

**Android 8.0 이상**에서 `Timerchine-1.2.0-android.apk`를 받아 설치하세요. Android에서 설치에 사용한 브라우저나 파일 앱의 ‘이 출처 허용’을 요청할 수 있습니다. 타이머를 시작할 때 알림과 ‘알람 및 리마인더’ 권한을 요청하면 허용해 주세요.

Android 설정에서 앱을 강제 종료하면 알람 예약과 재생이 중단되므로 앱을 다시 열어 상태를 확인하세요. 기기를 재부팅하면 실행 중이던 타이머는 중단되며 다시 시작해야 합니다. 알림·음량·방해 금지·제조사의 절전 설정에 따라 알림과 재생 동작이 달라질 수 있습니다.

PC 버전처럼 새 컴파일 빌드로 업데이트하면 **타이머와 일반 설정은 기본값으로 초기화하고 저장한 프리셋은 유지**합니다. 유지된 프리셋을 다시 불러와 적용하고, 외부 링크 이용 확인·화면 닫기 방식 등도 다시 설정해 주세요. 다운로드 캐시는 업데이트만으로 삭제하지 않습니다.

## 첨부 자료

- `Timerchine-1.2.0-android.apk`: 설치용 서명 APK
- `Timerchine-1.2.0-android-source.zip`: 앱·네이티브 미디어 도구의 소스, 빌드 스크립트와 라이선스
- `SHA256SUMS.txt`: 다운로드 파일의 SHA-256 검증값

앱 소스는 GPL-3.0-only, 포함된 글꼴은 OFL-1.1 조건으로 제공됩니다. Android용 yt-dlp·Python·QuickJS·FFmpeg와 관련 구성 요소에는 각각의 라이선스가 적용됩니다. 소스와 사용 안내는 저장소의 `mobile/android`에서 확인할 수 있습니다.
