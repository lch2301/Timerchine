# 타이머신 Android 개인정보 안내

타이머신 Android는 계정 가입 없이 사용합니다. 광고·분석 SDK를 포함하지 않으며, 타이머 설정과 프리셋을 개발자의 서버로 전송하지 않습니다.

## 기기에 저장하는 정보

- 타이머의 이름, 시간, 모드, 음량과 표시 설정, 설정 복구를 위한 이전 사본
- 프리셋 이름, 재생 목록의 파일 URI·음원 주소와 셔플 설정
- 사용자가 선택한 파일을 읽기 위한 Android의 지속 접근 권한
- 링크에서 내려받은 음원·제목·썸네일, 재생을 위해 변환한 오디오와 재생 위치
- 알람음 선택과 화면 닫기 방식, 외부 링크 이용 확인 상태

설정과 캐시는 앱 전용 저장소에 보관하며, 선택한 문서의 지속 접근 권한은 Android가 관리합니다. 앱을 삭제하거나 Android 설정에서 앱 데이터를 지우면 앱의 설정·캐시가 삭제됩니다. 별도로 내보낸 파일은 해당 위치에 남습니다. 음원을 선택할 때는 Android의 파일 선택기를 사용하며, 전체 저장소를 읽는 권한은 요구하지 않습니다. 앱 데이터의 Android 클라우드 백업과 기기 간 자동 전송은 사용하지 않습니다.

새 컴파일 빌드로 업데이트하면 PC 버전처럼 타이머와 일반 설정을 기본값으로 되돌리고 프리셋은 유지합니다. 외부 링크 이용 확인과 화면 닫기 방식 등은 다시 설정해야 합니다. 업데이트나 타이머 삭제만으로 내려받은 음원·썸네일·변환 파일을 삭제하지는 않습니다.

## 네트워크 연결

외부 링크의 제목·썸네일을 확인하거나 음원을 준비하면 해당 사이트와 미디어·이미지 서버에 연결합니다. 이때 서버는 일반적인 인터넷 연결과 같이 IP 주소와 요청 주소 등 접속 정보를 받을 수 있습니다. 타이머신이 별도의 음원 중계 서버로 이를 전송하지는 않습니다. 주소에 인증 토큰이나 개인 정보가 포함되어 있다면 타이머 설정이나 재생 목록에도 해당 주소가 저장됩니다. 임시로 생성하는 추출 정보 파일은 정상적인 작업 완료·실패·취소 처리 시 삭제하며, 강제 종료 시에는 남을 수 있습니다.

내려받은 음원과 썸네일은 앱 전용 저장소에 캐시합니다. 준비가 끝난 음원의 재생에는 이 파일을 사용합니다. 사용자가 파일로 내보내기를 선택하면 지정한 저장 위치에도 복사됩니다. HTTP 링크는 암호화되지 않은 연결을 사용할 수 있으며 HTTPS 링크는 서버가 제공하는 HTTPS 연결을 사용합니다.

파일 선택기에 클라우드 저장소를 연결한 경우에는 해당 파일 제공 앱이 파일을 내려받을 수 있습니다. 이 연결과 처리 방식은 그 제공 서비스의 정책을 따릅니다.

## 사용하는 Android 권한

| 권한 또는 접근 | 목적 |
| --- | --- |
| 알림 | 재생 제어와 타이머 종료 상태 표시 |
| 알람 및 리마인더 | 타이머 종료 시각의 알람 실행·역알람 음악 종료 |
| 포그라운드 서비스·미디어 재생 | 화면을 나간 상태의 음악 재생과 알람 소리 |
| 절전 방지 | 음악·알람이 재생되는 동안 필요한 처리 유지 |
| 인터넷 | 사용자가 추가한 외부 링크의 정보·썸네일·음원 다운로드 |
| 선택한 문서 접근 | 사용자가 직접 고른 음원 읽기 |
| 기기 재시작 알림 수신 | 재부팅 전 실행 중이던 타이머를 중단 상태로 정리 |

마이크·연락처·위치 권한은 사용하지 않습니다.
