# 타이머신 Android 사용 안내

## 타이머

기본 알람은 시간이 끝나면 소리가 납니다. 시간을 정하고 시작 버튼을 누르세요. 여러 타이머를 각각 사용하거나 전체 시작·중단·재시작으로 함께 제어할 수 있습니다.

타이머가 중단되어 있을 때는 시·분·초 입력 영역에 청회색 사각형 배경이 표시됩니다. 어느 자리를 눌러도 해당 칸 전체를 새로 입력하며, 첫 숫자는 일의 자리부터 들어갑니다. 예를 들어 `1`은 `01`, 이어서 `2`를 입력하면 `12`가 됩니다. 실행 중에는 입력 배경이 숨겨지고 남은 시간을 표시합니다. 중단 버튼은 차분한 색의 사각형 아이콘입니다.

타이머별 알람 설정에서 내장 멜로디·내 파일·외부 링크·재생 목록을 선택할 수 있습니다. 음량은 슬라이더 조작을 마치거나 숫자 입력을 확정하면 바로 반영되며, 알람 설정을 취소해도 이 음량 변경은 유지됩니다.

## 역알람

타이머에서 역알람 모드를 선택하고 알람음이나 재생 목록을 지정하세요. 타이머가 실행되는 동안 음악을 듣고, 시간이 끝나 음악이 멈추는 순간을 알림으로 사용할 수 있습니다. 중단하면 음악도 멈춥니다.

정해진 시간 동안 활동하거나 어떤 시각까지 기다리는 동안 다른 일을 하기에 적합한 방식입니다. 음악이 멈춘 것을 알아차리기 어려운 수면 중이나 주변 소음이 큰 상황에는 기본 알람을 사용하세요. 역알람의 시간이 끝날 때는 별도의 종료 알람음을 재생하지 않습니다.

## 음원과 프리셋

재생 목록의 파일 추가로 휴대전화에서 음원을 선택할 수 있습니다. 선택한 파일을 계속 읽을 수 있도록 Android 파일 선택기의 접근 권한을 보관합니다. 원본 파일을 이동·삭제하거나 파일 제공 앱에서 권한을 철회하면 다시 선택해야 할 수 있습니다.

온라인 음원은 HTTP·HTTPS의 공개 영상·오디오 링크로 추가합니다. 파일 확장자는 필요하지 않습니다. 사용자 이름·비밀번호가 포함된 주소는 사용할 수 없습니다. yt-dlp가 지원하는 페이지에서 제목·썸네일을 미리 확인하며, 저장하면 다운로드 진행률과 함께 음원을 준비합니다. 완료된 파일은 기기 내 캐시에서 재생하고, 파일 위치 안내에서 저장 파일을 확인하거나 별도 파일로 내보낼 수 있습니다.

외부 링크 이용 안내에서 다운로드·개인 알람 이용 권한과 제공 사이트의 이용 조건을 확인해 주세요. 공개된 단일 콘텐츠 중 직접 HTTP·HTTPS로 받을 수 있는 오디오를 사용합니다. 로그인·구독·구매·연령·지역 제한 콘텐츠, 실시간 방송, DRM 및 암호화·분할 스트림은 PC 1.2.0과 같은 기준으로 제외합니다. 원 사이트의 변경이나 인터넷 상태에 따라 음원 준비가 실패할 수 있습니다.

기본 Android 재생기가 지원하지 않는 로컬 미디어는 포함된 FFmpeg로 재생 가능한 오디오를 준비합니다. 이 과정에서 변환 시간과 저장 공간이 추가로 필요할 수 있습니다.

처음 실행하면 ‘기본 프리셋’이 선택되어 있습니다. 프리셋 팝업에서 이름을 입력해 새 프리셋을 생성하면 편집 중인 목록을 유지한 채 그 프리셋이 즉시 선택되고 팝업이 닫힙니다. 재생 목록을 편집한 뒤 **저장**을 누르면 현재 선택한 프리셋에 내용이 저장됩니다. 다른 프리셋을 선택하고 **불러오기**를 누르면 저장해 둔 목록과 셔플 설정을 가져옵니다. 셔플을 켜면 목록을 무작위 순서로 재생합니다.

재생 목록 창의 저장은 프리셋과 현재 알람 설정의 편집 내용에 반영됩니다. 실제 타이머에도 적용하려면 이어서 **알람 설정의 저장**을 누르세요. 알람 설정을 취소하더라도 이미 재생 목록 창에서 저장한 프리셋은 유지됩니다.

## 화면을 나간 상태에서 사용

역알람 음악은 앱 화면을 나가거나 휴대전화를 잠가도 재생됩니다. 재생 중에는 Android의 미디어 재생 알림이 표시되며, 알림의 제어 버튼으로 타이머와 재생을 조작할 수 있습니다. 잠금 화면의 표시 여부와 모양은 기기 설정에 따릅니다. 전화를 받거나 다른 앱에서 소리를 재생하면 Android의 오디오 포커스 정책에 따라 재생이 중단되거나 음량이 바뀔 수 있습니다.

뒤로 가기로 화면을 닫을 때 **백그라운드로 보내기**를 선택하면 타이머와 음악이 계속 동작합니다. **완전 종료**를 선택하면 타이머와 재생을 종료합니다. 저장한 닫기 방식은 앱 설정의 ‘화면을 닫으면 백그라운드 재생’에서 바꿀 수 있습니다.

타이머가 끝나는 시각은 Android 알람 기능으로 예약됩니다. 타이머를 시작할 때 ‘알람 및 리마인더’ 허용을 요청하면 설정에서 허용해 주세요. Android 13 이상에서는 알람용 정확한 알람 권한이 설치 시 부여되며, 알림을 표시하려면 알림 권한도 허용해야 합니다. 알림 소리·기기 음량·방해 금지 설정은 Android의 설정을 따릅니다.

앱을 Android 설정에서 **강제 종료**하면 알람 예약과 재생이 중단됩니다. 앱을 다시 열어 타이머 상태를 확인해 주세요. 휴대전화를 재부팅하면 실행 중이던 타이머를 중단 상태로 바꾸므로, 필요한 타이머를 다시 시작해 주세요. 제조사의 백그라운드 제한이나 절전 설정에 따라 동작이 달라질 수 있습니다.

## 저장 내용

타이머 설정, 프리셋과 재생 목록은 앱 전용 저장소에 보관합니다. **버전·빌드가 바뀌어도 타이머·알람·음량·앱 설정·재생 목록·프리셋과 선택 상태를 유지**합니다. 외부 링크 이용 확인·화면 닫기 방식·저장된 재생 위치와 순서도 업데이트를 이유로 초기화하지 않습니다. 새로운 설정 항목에만 기본값을 적용합니다. 기존 데이터가 유지되는 업데이트 설치에는 동일한 앱 패키지와 서명이 필요합니다.

다운로드한 음원·썸네일·변환 파일은 업데이트나 타이머 삭제만으로 지우지 않습니다. 앱 삭제 또는 앱 데이터 초기화는 설정·프리셋과 이 캐시를 지웁니다. 별도로 내보낸 음원 복사본은 저장한 위치에 남습니다. Windows 설정 파일을 자동으로 가져오지는 않습니다.
