타이머신 Android — 오디오·외부 링크 구성 요소

타이머신 Android 소스는 GPL-3.0-only로 제공됩니다.

외부 링크는 yt-dlp 2026.10.21과 youtubedl-android 0.18.1을 사용합니다.
Android용 Python 3.12.11, QuickJS 2025-04-26, FFmpeg·ffprobe가 포함됩니다.
yt-dlp 엔진과 함께 포함되는 JavaScript EJS 구성 요소에는 Unlicense·MIT·ISC가 적용됩니다.
youtubedl-android 래퍼의 라이선스는 GPL v3이며, 원본 소스와 빌드 자료는
Android 소스 자료의 native/python/upstream-wrapper에 보관합니다.

Python 런타임에는 OpenSSL, PyCryptodome, Expat, zlib, libffi, liblzma,
SQLite, bzip2, ncurses와 Termux의 Android 호환 라이브러리가 포함됩니다.
타이머신에서 사용하지 않는 readline·history·gdbm 및 Mutagen 모듈은
공식 AAR의 해시를 확인한 뒤 소스 빌드 단계에서 제외합니다.

FFmpeg는 독립된 Android용 디코딩·분석 실행 프로그램으로 사용합니다.
PC와 같은 리비전 9a9b70bb8c의 FFmpeg를 LGPL 2.1 이상 조건으로 빌드하고,
Game_Music_Emu(LGPL 2.1 이상), libopenmpt(BSD·Boost 및 포함 고지),
dav1d(BSD 2-Clause)를 정적 링크합니다. NDK r28c의 C++ 컴파일러 런타임도
각 원문 고지와 함께 제공합니다.
FFmpeg의 적용 라이선스, 소스와 빌드 설정은 native/ffmpeg에서 확인할 수 있습니다.
수정한 도구로 빌드하고 앱에 포함할 수 있으며 원 제작자의 서명 개인키는 필요하지 않습니다.

Java 구성 요소인 AndroidX, Kotlin, Jackson, Apache Commons 등의 실제
모듈 이름과 버전은 APK의 licenses/dependencies/runtime-dependencies.json에 기록됩니다.
AndroidX, Kotlin 표준 라이브러리, JetBrains annotations와 Guava listenablefuture는
Apache License 2.0 조건으로 사용하며, 원본 AAR·JAR에 고지가 없는 경우에도
공식 라이선스 원문을 별도로 보관하여 아래에 포함합니다.
