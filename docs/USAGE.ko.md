# 타이머신 1.3.0 사용 안내

## 실행

Windows 10 22H2 이상 또는 Windows 11 x64용입니다. 실행 ZIP을 압축 해제한 뒤 `Timerchine.exe`를 실행하세요. .NET 런타임과 글꼴·오디오 도구가 포함되어 있습니다.

실행 시 관리자 권한을 요청합니다. 미서명 배포본은 Windows 보안 설정에 따라 실행이 제한될 수 있습니다. 공식 저장소의 릴리스에서 받은 파일인지 확인하고, 함께 제공된 SHA256과 대조할 수 있습니다.

## 시간 입력과 시작·중단

- 시·분·초 숫자칸의 어느 자리를 눌러도 해당 칸 전체를 새로 입력합니다. 첫 숫자는 일의 자리부터 들어가며 `1` → `01`, 이어서 `2` → `12`로 표시됩니다. 엔터 또는 다른 영역 클릭으로 저장합니다.
- 시는 00~99, 분과 초는 00~59까지 설정합니다.
- 대기·중단 상태의 숫자칸에는 청회색 배경이 표시되고, 실행 중에는 배경이 사라집니다.
- 각 타이머의 시작·중단·재시작 버튼을 사용하거나 전체 버튼으로 함께 제어합니다.
- 단축키는 타이머별 또는 전체 동작에 맞게 직접 지정할 수 있습니다.

## 게임 오버레이

설정의 **게임 오버레이 표시**를 켜면, 활성화된 게임 창에서 모든 타이머의 이름과 남은 시간이 표시됩니다. 기본 위치는 오른쪽 끝, 위에서 30% 지점이며 이름과 시간의 오른쪽 끝이 맞춰집니다. 시간은 항상 우측 정렬합니다. 처음에는 켜져 있으며, 이 설정을 끄면 즉시 숨겨집니다. 게임을 닫거나 최소화하거나 브라우저·바탕화면·다른 일반 앱으로 전환하면 표시하지 않습니다.

오버레이는 반투명한 이름과 시간만 표시합니다. 클릭이나 키보드 입력을 가로채지 않으며, 타이머신을 트레이로 보내도 타이머와 함께 계속 동작합니다. 창모드에서는 게임의 화면 영역 안에 표시하고, 테두리 없는 전체화면에서는 해당 게임 화면을 기준으로 표시합니다.

창모드와 테두리 없는 전체화면을 지원하며 독점 전체화면은 지원하지 않습니다. Direct3D·OpenGL·Vulkan 모듈, 게임 엔진·설치 경로 및 3D GPU 활동을 조합해 자동 감지합니다. 모듈 조회가 제한된 게임은 운영체제의 3D GPU 활동이나 게임 엔진 창 정보로 감지합니다. 브라우저와 일반 Windows 창은 제외하지만 자동 분류가 모든 프로그램의 게임 여부를 보장하지는 않습니다.

감지는 PC 안에서 수행되며, 실행 중인 프로그램 정보나 타이머 내용을 외부 서버로 전송하거나 감지 기록을 파일로 저장하지 않습니다.

### 오버레이 모양 설정

앱의 **설정 → 오버레이 → 오버레이 설정** 버튼을 누르면 별도 팝업이 열립니다.

- **위치:** 가로·세로 위치를 각각 0~100%로 지정합니다. 게임 화면에서 오버레이가 들어갈 수 있는 영역을 기준으로 하며, 가로 0%는 왼쪽·100%는 오른쪽, 세로 0%는 위·100%는 아래입니다. 기본값은 가로 100%·세로 30%입니다.
- **투명도:** 0~90%로 조절합니다. 값이 클수록 글자가 더 투명해지며 기본값은 50%입니다.
- **시간 글자 크기:** 12~96pt 범위에서 소수 첫째 자리까지 지정하며 기본값은 15.0pt입니다.
- **타이머 이름 크기:** 8~48pt 범위에서 소수 첫째 자리까지 지정하며 기본값은 13.0pt입니다.
- **이름 가로 정렬:** 게이지로 0~100% 사이를 조절합니다. 0%는 시간의 왼쪽 끝, 50%는 실제 시간 글자와 이름의 가로 중심, 100%는 시간의 오른쪽 끝에 맞춥니다. 기본값은 100%입니다. 이름 정렬을 바꿔도 시간의 위치는 유지되며 항상 우측 정렬합니다.

게이지를 움직이거나 값을 바꾸면 팝업 안의 미리보기에 바로 표시됩니다. **저장**을 누르면 실제 게임 오버레이에 적용되고, **취소**하면 기존 설정을 유지합니다. 이 팝업은 앱 본체에서 열며 게임 위의 오버레이에는 조작 버튼이 추가되지 않습니다. 저장한 위치·투명도·글자 크기·이름 가로 정렬은 앱을 종료하거나 업데이트해도 유지됩니다. 이전 이름 정렬의 좌측·중앙·우측 설정은 각각 0%·50%·100%로 이어집니다. 위 기본값은 새 항목이나 저장값이 없는 항목에만 적용하며, 이미 저장한 다른 설정은 바꾸지 않습니다.

## 기본 알람과 역알람

기본 알람은 시간이 끝나면 소리를 재생합니다. 역알람은 타이머가 작동하는 동안 음악을 재생하고, 중단하거나 시간이 끝나면 음악을 일시정지합니다. 다시 시작하면 멈춘 위치에서 이어집니다.

정해진 시간 동안 무언가를 하거나 일정 시간까지 기다려야 할 때, 음악을 들으며 다른 일을 하고 음악의 멈춤을 시간의 신호로 사용할 수 있습니다. 수면 중이거나 음악의 변화를 놓치기 쉬운 상황에서는 기본 알람을 사용하세요. 사용할 오디오 장치와 음량도 함께 확인하세요.

## 재생 목록과 프리셋

1. 알람 설정에서 재생 목록 설정을 엽니다.
2. 파일 추가로 항목을 등록합니다. 목록은 마지막 항목 뒤에 반복되며 무작위 재생도 선택할 수 있습니다.
3. 프리셋 버튼에서 이름을 입력하고 생성하면 새 프리셋이 선택되고 팝업이 닫힙니다.
4. 재생 목록 창에서 저장하면 선택된 프리셋에 목록과 무작위 재생 설정을 저장합니다.
5. 기존 프리셋은 선택 후 불러오기를 누릅니다. 타이머에 적용하려면 상위 알람 설정에서도 저장합니다.

처음에는 기본 프리셋이 하나 생성되어 선택됩니다. 프리셋을 생성하는 것만으로 편집 중인 목록이 저장되지는 않습니다. 재생 목록 창의 저장 버튼을 사용하세요.

프리셋에는 파일 자체가 아닌 경로와 재생 정보가 저장됩니다. 다른 PC로 옮기면 해당 PC에서 사용할 수 있는 파일 경로를 다시 지정해야 할 수 있습니다. 목록에서 항목을 삭제해도 원본 파일은 삭제되지 않습니다.

재생 목록 창에서 이미 저장한 프리셋은 상위 알람 설정을 취소해도 유지됩니다. 선택 해제 후 목록을 저장하면 프리셋 라이브러리는 갱신되지 않습니다.

## 외부 링크

외부 링크는 설정에서 이용 권한을 확인한 뒤 등록할 수 있습니다. 콘텐츠의 권리와 제공 사이트의 이용 조건을 확인하고, 사용할 권한이 있는 자료만 이용하세요. 앱의 확인란이 콘텐츠 이용 허락을 대신하지 않습니다.

다운로드한 알람 파일의 전달·공개 재생 등은 원래 콘텐츠의 이용 조건에 따릅니다.

## 설정과 데이터

`%LOCALAPPDATA%\IntervalTimer`에 타이머 설정, 프리셋과 미디어 캐시가 저장됩니다. 사용자 설정과 개인 미디어는 배포 ZIP에 포함되지 않습니다.

버전이나 빌드가 바뀌어도 타이머 이름·설정 시간·알람·음량·단축키·앱 설정·재생 목록·프리셋 선택과 라이브러리를 유지합니다. 새 항목에만 기본값을 적용하며, 업데이트를 이유로 기존 저장값을 초기화하지 않습니다. 실행 파일을 교체해도 위 저장 폴더를 그대로 사용합니다.

닫기 동작을 트레이 최소화로 선택했다면 창을 닫아도 타이머가 계속 작동합니다. 종료하려면 트레이 메뉴의 종료를 사용하세요.
