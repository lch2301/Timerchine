# 타이머신 Timerchine v1.2.0

**알람이 울리는 순간도, 음악이 멈추는 순간도 시간의 신호로.**

시간이 끝나면 소리가 울리는 기본 알람을 제공합니다. 정해진 시간 동안 무언가를 하거나 때가 될 때까지 기다려야 할 때는 역알람 모드를 선택하세요. 음악을 들으며 다른 일을 하고, 음악이 끊기는 순간을 시간의 신호로 사용할 수 있습니다.

역알람은 음악의 멈춤을 알아차릴 수 있는 상황에 어울립니다. 수면 중처럼 그 변화를 놓치기 쉬운 상황에서는 기본 알람을 사용하세요.

## 주요 기능

- 여러 타이머와 개별·전체 시작, 중단, 재시작
- 타이머별 알람음, 음량, 역알람과 단축키
- 재생 목록, 무작위 재생, 프리셋 생성·선택·불러오기·저장
- 기본 프리셋 자동 생성과 새 프리셋 즉시 선택
- 모래시계 표시와 트레이 최소화
- 대기·중단 상태에서 시간 입력칸 배경 표시, 실행 중 숨김

## 다운로드

- `Timerchine-1.2.0-win-x64.zip`: Windows 실행 파일과 사용 안내
- `Timerchine-1.2.0-source.zip`: 타이머신 소스와 빌드 자료
- `Timerchine-1.2.0-third-party-source-materials.zip`: 제3자 원본 소스와 빌드 자료
- `SHA256SUMS.txt`: 다운로드 파일의 SHA256

Windows 10 22H2 이상 또는 Windows 11 x64용입니다. 실행 ZIP을 압축 해제하고 `Timerchine.exe`를 실행하세요. .NET 런타임을 별도로 설치하지 않고 사용할 수 있습니다.

소스 ZIP과 제3자 소스·빌드 자료를 함께 제공합니다. 외부 도구 수정본의 해시를 생성하고 앱에 넣어 빌드하는 방법은 [외부 도구 수정 안내](https://github.com/lch2301/Timerchine/blob/main/docs/MODIFYING-TOOLS.ko.md)에 있습니다.

## 사용 시 알아둘 점

- 1.2.0 실행 파일은 관리자 권한을 요청합니다.
- 미서명 배포본은 Windows 보안 설정에 따라 안내가 표시되거나 실행이 제한될 수 있습니다.
- 설정과 프리셋은 `%LOCALAPPDATA%\IntervalTimer`에 저장됩니다.
- 새 빌드에서는 타이머 설정이 초기화될 수 있으며 프리셋 라이브러리는 별도로 유지됩니다.
- 외부 링크는 콘텐츠의 권리와 제공 사이트의 이용 조건에 맞게 사용하세요.
