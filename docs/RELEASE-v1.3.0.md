# 타이머신 Windows 1.3.0

게임 화면에서 타이머 이름과 남은 시간을 확인할 수 있는 **게임 오버레이**를 추가했습니다.

- 기본 위치는 오른쪽 끝(가로 100%), 위에서 30% 지점이며 시간은 항상 우측 정렬합니다.
- 기본 투명도는 50%, 남은 시간 글자는 15.0pt, 타이머 이름 글자는 13.0pt입니다.
- 앱의 **설정 → 오버레이 → 오버레이 설정**에서 위치·투명도·시간 글자 크기·타이머 이름 크기를 조절할 수 있습니다.
- **이름 가로 정렬**을 0~100% 게이지로 연속 조절할 수 있습니다. 0%는 시간의 왼쪽 끝, 50%는 시간 글자와 이름의 가로 중심, 100%는 오른쪽 끝에 맞추며 기본값은 100%입니다.
- 이름의 중앙 위치가 실제 시간 글자의 중앙과 일치하도록 수정했습니다.
- 팝업 안의 미리보기로 확인한 뒤 저장하면 적용됩니다. 취소하면 기존 설정을 유지합니다.
- 반투명 글자만 표시하며 마우스 입력과 키보드 포커스를 유지합니다.
- 게임에서 브라우저·바탕화면·일반 앱으로 전환하면 숨겨집니다.
- 트레이에 최소화한 상태에서도 표시되며 설정에서 켜거나 끌 수 있습니다.
- 창모드와 테두리 없는 전체화면을 지원합니다. 독점 전체화면은 지원하지 않습니다.

그래픽 API·게임 엔진·설치 경로와 3D GPU 활동을 바탕으로 자동 감지합니다. 모듈 조회가 제한된 게임도 게임 엔진 창 정보나 운영체제의 3D GPU 활동으로 감지합니다. 개별 게임에서의 표시 여부는 사용하는 환경에서 확인해 주세요.

Windows 10 22H2 이상 또는 Windows 11 x64용입니다. 실행 ZIP 전체를 압축 해제한 뒤 `Timerchine.exe`를 실행하세요. 기본 알람, 역알람, 재생 목록·프리셋과 단축키는 계속 제공됩니다.

버전·빌드가 달라져도 타이머·앱 설정·단축키·재생 목록·프리셋과 선택 상태가 유지됩니다. 저장한 오버레이의 위치·투명도·글자 크기·이름 가로 정렬도 유지합니다. 이전 이름 정렬의 좌측·중앙·우측 설정은 각각 0%·50%·100%로 이어집니다. 기본값은 새 항목이나 저장값이 없는 항목에만 적용하며, 이미 저장한 다른 설정은 바꾸지 않습니다. 시·분·초 칸은 어느 자리를 눌러도 첫 숫자를 일의 자리부터 입력합니다. 자세한 사용법은 함께 제공되는 사용 안내와 README를 확인하세요.

## 다운로드

- **일반 사용자:** `Timerchine-1.3.0-win-x64.zip`을 받아 전체 압축을 풀고 `Timerchine.exe`를 실행하세요.
- **Windows 앱 소스:** `Timerchine-1.3.0-source.zip`에 소스·리소스·빌드 및 검증 자료가 들어 있습니다.
- **파일 무결성 확인:** `SHA256SUMS.txt`의 SHA256과 비교할 수 있습니다.
- **외부 도구 소스:** 포함된 도구는 1.2.0과 동일하며, [원본 소스·빌드 자료 ZIP](https://github.com/lch2301/Timerchine/releases/download/v.1.2.0/Timerchine-1.2.0-third-party-source-materials.zip)을 계속 제공합니다.

업데이트할 때는 실행 중인 이전 앱을 트레이 메뉴의 **종료**로 닫은 뒤 새 실행 파일을 사용하세요. 기존 설정 폴더를 삭제하지 않아도 됩니다.

이번 릴리스는 **Windows용**입니다. Android 앱은 별도 릴리스로 제공합니다.
